# Jarema's digital garden, version 5 (Astro)

A personal website built with [Astro](https://astro.build).

This repository is hosted on [Codeberg](https://codeberg.org/0jar/website) and mirrored on [GitHub](https://github.com/0jar/website) and [GitLab](https://gitlab.com/0jar/website).

See the site in action:

- [https://jarema.me](https://jarema.me) (main)
- [https://z.is-a.dev](https://z.is-a.dev) (backup, Vercel build)
- [https://jarema.neocities.org](https://jarema.neocities.org) (Neocities build)

## Features

- Responsive design with light, dark, and system themes
- Nine interface languages, with RSS, Atom, and JSON feeds
- IndieWeb support for h-card, IndieAuth, and Webmention
- Global command palette and keyboard shortcuts
- 2048 and Tetris
- Random tools at my disposal

## Development

This repo is mostly for my personal site, feel free to experiment with it though! See [DEVELOPING.md](DEVELOPING.md) for guidance.
